# DENTIX client demo

Public, presentation-only preview for the DENTIX patient booking flow and Admin CRM.

- `/` — patient website and in-memory demo booking flow
- `/admin/` — Admin CRM using local demo fixtures
- no Supabase connection
- no Google Calendar connection
- no real patient data
- no production booking endpoint

Canonical sources remain separate:

- patient UI: `optidigitalagent/dentix-rebrand`, branch `feature/dentix-booking-crm`
- admin/backend: private `optidigitalagent/dentix-admin-crm`, branch `main`

This repository is not a production source of truth.
